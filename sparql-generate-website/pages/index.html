SPARQL-Generate

An extension of SPARQL 1.1 to generate RDF or text from RDF datasets and from documents in heterogeneous formats: JSON, CSV, XML, HTML, GeoJSON, CBOR, SQL databases, plain text, and streams from MQTT, WebSocket or repeated HTTP requests.

Open the playground Read the documentation Download the engine 
PREFIX iter: <http://w3id.org/sparql-generate/iter/>
PREFIX schema: <http://schema.org/>
BASE <http://example.org/>

GENERATE {
  <person/{?id}> a schema:Person ;
    schema:name ?name .
}
ITERATOR iter:CSV(<people.csv>, "id", "name") AS ?id ?name

The language

  • SPARQL 1.1 queries are SPARQL-Generate queries.
  • GENERATE outputs RDF, TEMPLATE outputs text, SELECT outputs solutions, FUNCTION defines functions.
  • SOURCE and ITERATOR bind variables to documents and to their parts.
  • Expressions in IRIs and literals: <person/{?id}>.
  • Named queries with parameters, called from other queries.

Use it

  • in the playground, with a step-by-step tutorial;
  • with the executable JAR (Java 17);
  • as a Java library on Apache Jena, from Maven Central;
  • in Visual Studio Code.
