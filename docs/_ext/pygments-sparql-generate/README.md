# pygments-sparql-generate (vendored)

A copy of the Pygments lexer of
[highlight-sparql-generate](https://github.com/sparql-generate/highlight-sparql-generate)
(`pygments-sparql-generate/`, commit 9dfb1a8), so that the
documentation builds on ReadTheDocs before the package is on PyPI.
`docs/requirements.txt` installs it. Do not edit it here: update it from
highlight-sparql-generate.
