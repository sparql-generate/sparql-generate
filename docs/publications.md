# Publications

## How to cite

To cite SPARQL-Generate, cite the ESWC 2017 paper, which defines the language and its semantics:

> Maxime Lefrançois, Antoine Zimmermann, Noorani Bakerally. *A SPARQL Extension for Generating RDF from Heterogeneous Formats*. In The Semantic Web, ESWC 2017, Lecture Notes in Computer Science 10249, pp. 35-50. Springer, 2017. [doi:10.1007/978-3-319-58068-5_3](https://doi.org/10.1007/978-3-319-58068-5_3)

```bibtex
@inproceedings{lefrancois2017sparql,
  title     = {A {SPARQL} Extension for Generating {RDF} from Heterogeneous Formats},
  author    = {Lefran{\c{c}}ois, Maxime and Zimmermann, Antoine and Bakerally, Noorani},
  booktitle = {The Semantic Web. ESWC 2017},
  series    = {Lecture Notes in Computer Science},
  volume    = {10249},
  pages     = {35--50},
  publisher = {Springer},
  year      = {2017},
  doi       = {10.1007/978-3-319-58068-5_3}
}
```

The repository has a [`CITATION.cff`](https://github.com/sparql-generate/sparql-generate/blob/master/CITATION.cff) file, which GitHub shows as *Cite this repository*.

## Papers

- Maxime Lefrançois, Antoine Zimmermann, Noorani Bakerally. *A SPARQL Extension for Generating RDF from Heterogeneous Formats*. Extended Semantic Web Conference (ESWC 2017), Portorož, Slovenia, May 2017. LNCS 10249, pp. 35-50. [doi:10.1007/978-3-319-58068-5_3](https://doi.org/10.1007/978-3-319-58068-5_3), [PDF](http://www.maxime-lefrancois.info/docs/LefrancoisZimmermannBakerally-ESWC2017-Generate.pdf). The grammar and the formal semantics of the language, as an extension of the SPARQL 1.1 algebra, and a comparison with RML on CSV documents (see [the archived evaluation](archive/evaluation-2017.md)).
- Maxime Lefrançois, Antoine Zimmermann, Noorani Bakerally. *Flexible RDF Generation from RDF and Heterogeneous Data Sources with SPARQL-Generate*. EKAW 2016 Satellite Events, Bologna, Italy, November 2016. LNCS 10180, pp. 131-135. [doi:10.1007/978-3-319-58694-6_16](https://doi.org/10.1007/978-3-319-58694-6_16), [PDF](http://www.maxime-lefrancois.info/docs/LefrancoisZimmermannBakerally-EKAW2016-Flexible.pdf). The demonstration of the first version.
- Maxime Lefrançois, Antoine Zimmermann, Noorani Bakerally. *Génération de RDF à partir de sources de données aux formats hétérogènes*. 17e conférence Extraction et Gestion des Connaissances (EGC 2017), Grenoble, France, January 2017. [PDF](http://www.maxime-lefrancois.info/docs/LefrancoisZimmermannBakerally-EGC2017-Generation.pdf). In French.

Version 2 of the language (`TEMPLATE`, `SELECT` with binding clauses, `FUNCTION`, named queries with a signature, `LIST`) has no dedicated publication yet; this documentation describes it.
