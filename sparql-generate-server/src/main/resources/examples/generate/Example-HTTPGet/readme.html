The iterator function iter:HTTPGet polls a Web resource: it binds the response of a HTTP GET operation, repeated at a fixed interval.

  • Param 1: the URL of the resource;
  • Param 2: the number of seconds between two calls;
  • Param 3 (optional): the total number of calls. Without it, the iterator never ends.

This query reads the report of an air quality station three times, every two seconds, and generates one ex:Report per response. With the return stream option, the triples appear as the responses arrive.
