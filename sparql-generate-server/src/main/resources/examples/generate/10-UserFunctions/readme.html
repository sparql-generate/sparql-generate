A FUNCTION query defines a SPARQL function in SPARQL-Generate. Its IRI is the name of the function, its signature lists the parameters, and its body is one expression:

FUNCTION <function_iri> ( ?param1, ?param2 ) { expression }

The named query tuto:aqiLevel of this example maps an air quality index to a level. The main query calls it like any SPARQL function: when the engine meets an unknown function IRI, it looks up a FUNCTION query at that IRI, here in the queryset of the playground.

An error in the body of the function, for example an unbound argument (station 3 reports no index), leaves the variable of the BIND unbound, as for any SPARQL function.
