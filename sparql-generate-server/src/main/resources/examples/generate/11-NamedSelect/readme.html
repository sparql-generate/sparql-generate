A SELECT query can have a name and a signature. Another query then uses it as an iterator: ITERATOR <select_iri>( arguments ) AS ?var1 ?var2 ... binds the variables to the columns of each solution of the named SELECT query, in order.

The named query tuto:stations of this example reads the station reports 0 to ?max and selects their index, name and air quality index. The main query calls it with ?max = 10, keeps the stations whose index is above 25, and sorts them.

Named SELECT queries let a query reuse the extraction logic of another, in the same way as named GENERATE and TEMPLATE queries reuse output templates.
